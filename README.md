# DevProbe

An API Testing and Documentation Platform for developers.

## About

DevProbe is a full-stack web application designed to help developers execute HTTP requests, inspect API responses, organize requests into collections, and generate API documentation.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL

## Current Development Status

Day 1: Project setup and initial Express server.

## Planned Features

- HTTP request builder
- API response viewer
- Request collections
- User authentication
- Request history
- Environment variables
- Automated API testing
- API documentation generation

## Local Setup

1. Install Node.js and npm.
2. Clone this repository.
3. Install dependencies using `npm install`.
4. Create a `.env` file containing `PORT=3000`.
5. Start the development server using `npm run dev`.
6. Open `http://localhost:3000` in your browser.
